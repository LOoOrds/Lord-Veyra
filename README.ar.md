## التوزيع الرسمي

هذه ريبو التنزيل ودليل الاستخدام الرسميان لأداة **Lord Veyra**، بإدارة **Lords**. تحتوي الريبو على الشرح والصور والإصدارات المنشورة من المثبّت. لا تتضمن الشيفرة المصدرية للتطبيق أو أدوات الإدارة الخاصة.

**لم يُنشر أول Setup عام بعد.** سيظهر الإصدار وملف التنزيل وملاحظات التثبيت في [صفحة Releases](https://github.com/LOoOrds/Lord-Veyra/releases) عند جاهزيته. يشرح هذا الدليل طريقة استخدام الأداة، ولا يعني توفر مثبّت منشور حاليًا.

## المزايا

| الجزء | ما يقدمه |
|---|---|
| **البحث** | البحث في كتالوج الألعاب، ومراجعة خيارات التشغيل المتاحة، وإضافة الألعاب إلى مكتبتك. |
| **التشغيل** | الاختيار الصريح بين **Normal** و**Local** و**RPC Call** عند توفرها للعبة المحددة. |
| **الجلسات** | بطاقات عائمة، وعرض الجلسات النشطة، وسجل نشاط الحساب داخل Profile. |
| **الهوية** | ثيما **Lord Veyra** و**Veyra Galaxy**، وأحجام مختلفة للبطاقات، وخيار Full أو Reduced Motion. |
| **البروفايل** | تعديل اسم العرض والصورة مع القص، وفريم يتبع الثيم المختار. |

## البداية

1. احصل على بيانات حسابك من Lords؛ لا يوجد تسجيل حساب عام من داخل الأداة.
2. نزّل ملف **Setup.exe** المنشور في صفحة Releases عندما يتوفر.
3. افتح المثبّت، واختر المسار المقترح أو مجلدًا مخصصًا فارغًا، ثم أكمل التثبيت. يستطيع المثبّت تجهيز Microsoft WebView2 Runtime عند غيابه، وتتطلب هذه الخطوة الإنترنت.
4. اضغط **Launch Veyra**، ثم سجّل الدخول باسم المستخدم أو البريد الإلكتروني وكلمة المرور. يمكنك تفعيل **Remember me**.
5. افتح **Add** وابحث عن لعبة مدعومة وأضفها إلى **Library**، ثم اضغط **Play** واختر طريقة التشغيل المناسبة من الخيارات المتاحة.

لا يحتاج التثبيت العادي إلى أدوات تطوير أو تنزيل منفصل لبيانات التطبيق.

## الحساب والجهاز

- تحتاج الأداة إلى اشتراك صالح واتصال مستمر بالإنترنت.
- أول تسجيل دخول مؤهل يربط الحساب بجهاز Windows. تسجيل الخروج أو إزالة البرنامج لا يفك هذا الربط؛ تواصل مع Lords عند الحاجة إلى إعادة تعيين الجهاز.
- إنشاء الحسابات وإدارة الاشتراكات وإعادة تعيين الأجهزة من مسؤولية Lords. لا يحتاج المستخدم إلى دخول لوحة الإدارة الخاصة.
- يحمي Windows بيانات تسجيل الدخول المحفوظة محليًا، ويظل التحقق عبر الإنترنت مطلوبًا.

## الجلسات والبروفايل

الحد الافتراضي للجلسات المتزامنة **3**، ويمكن تغييره من Settings إلى قيمة بين **1 و10**. يُسمح بجلسة RPC Call واحدة في الوقت نفسه. خفض الحد لا يغلق الجلسات الحالية، لكنه يمنع إضافة جلسات جديدة حتى تتوفر مساحة.

إغلاق النافذة الرئيسية يخفي الأداة إلى شريط النظام. **End Session** ينهي الجلسة المحددة، و**Quit Veyra** ينهي الجلسات النشطة التابعة للأداة ثم يغلقها. وصول العداد الظاهر إلى نهاية 15 دقيقة لا ينهي الجلسة تلقائيًا.

يعرض Profile بيانات الحساب والاشتراك والجهاز النشط وسجل جلسات الألعاب. وقت الجلسات يسجل نشاط الأداة، ولا يضمن وقت لعب فعليًا داخل اللعبة أو اكتمال مهمة في خدمة خارجية.

## التحديث التلقائي

تتحقق النسخ المثبّتة المؤهلة من تحديثات التطبيق المنشورة عمدًا عند بدء التشغيل بعد التحقق من الحساب، وخلال التحقق الدوري الحالي. رفع Setup على GitHub عملية منفصلة عن تفعيل تحديث داخل الأداة.

إذا توفر تحديث أحدث وموقّع عند البداية، تعرض الأداة مراحل التنزيل والتحقق والتثبيت. أثناء الاستخدام يمكن تنزيل التحديث في الخلفية، ثم عرض **Update now** أو **Later**. ينتظر التثبيت انتهاء الجلسات النشطة والمعلّقة. توضح ملاحظات كل إصدار منشور السلوك الخاص به.

ملف Setup الذي نزلته سابقًا لا يتغير تلقائيًا؛ استخدم أحدث مثبّت منشور عند إجراء تثبيت جديد.

## المتطلبات وملاحظات التثبيت

- Windows 10 أو Windows 11 بإصدار **64-bit**.
- إنترنت يعمل وبيانات حساب يوفرها Lords.
- Microsoft WebView2 Runtime للتطبيق؛ يجهزه المثبّت عند الحاجة.
- مجلد تثبيت قابل للكتابة. التثبيت المقترح خاص بمستخدم Windows الحالي، والمسار المخصص يحتاج إلى مجلد محلي فارغ.

تستخدم نسخ التطوير الحالية **شهادة تطوير ذاتية التوقيع**، وليست شهادة ناشر موثوقة علنًا لدى Windows؛ لذلك قد تظهر رسائل متعلقة بالناشر أو سمعة الملف. التوقيع الذاتي لا يمنح ثقة Windows العامة.

## المساعدة والملاحظات

لمشكلات الحساب والاشتراك وربط الجهاز، تواصل مع Lords عبر قناة الدعم الخاصة المعتادة. لمشكلة قابلة للتكرار في التطبيق، [افتح Issue](https://github.com/LOoOrds/Lord-Veyra/issues) واكتب إصدار الأداة وإصدار Windows وخطوات حدوث المشكلة، مع صورة عند الحاجة. احذف بيانات الحساب من الصور. **لا تنشر كلمات مرور أو توكنات أو مفاتيح الإدارة.**
